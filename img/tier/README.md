# Tier表の見出し画像

見出し画像は、`img/tier/<時期>/<デッキ名>.webp` に保存します。

例:

```text
img/tier/2026-05-2nd-week/風花森.webp
img/tier/2026-06-1st-week/風花森.webp
```

同名デッキの画像を更新するときは既存の画像を上書きせず、新しい時期フォルダに保存します。これにより、過去環境と最新環境で別々の見出し画像を表示できます。

Tierデータの `environmentId` が `2026_05_w3`、`imageFile` が `メイドロボ` の場合は、`2026-05-3rd-week/メイドロボ.webp` を自動的に参照します。

次の週に同じデッキの画像がない場合は、その週より前で最も近い画像を表示します。たとえば5月第4週にメイドロボの画像がなければ、`2026-05-3rd-week/メイドロボ.webp` を引き継ぎます。

必要に応じて、`imageFile` に `img/tier/` からの相対パスを拡張子付きで直接設定することもできます。

```text
2026-06-1st-week/風花森.webp
```

`imageFile` が空の場合は、現在の既定環境である `2026-05-2nd-week` の画像を表示します。
